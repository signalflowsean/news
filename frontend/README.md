# Frontend (Vite + TypeScript)

Canvas-based visualization app. Rendering handled by Rust/Wasm engine.

## Prerequisites

- Node.js 18+
- Rust + wasm-pack (for engine builds)
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

## Setup

```bash
npm install
cargo install wasm-pack
```

## Development

**Frontend-only** (no backend data):
```bash
npm run dev
```
Opens at `http://localhost:5173`. Uses empty/stub data.

**Full-stack** (with real Neo4j data):
```bash
npm run build
cd ../backend && source ../.env && go run main.go
```
Visit `http://localhost:8080`.

## Build

Build wasm engine:
```bash
npm run build:wasm
```
Requires `wasm-pack`. Install with: `cargo install wasm-pack`

Production build:
```bash
npm run build
```
Outputs to `dist/`, served by Go backend.

## Directory Structure

```
frontend/
├── src/
│   ├── main.ts       # App entry, canvas setup
│   ├── types.ts      # TypeScript interfaces
│   ├── styles/       # CSS
│   └── wasm/         # Generated by wasm-pack (gitignored)
├── engine/           # Rust/Wasm crate
└── dist/             # Build output (gitignored)
```
